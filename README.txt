THE UNINVITED v0.1.0 - experimental Forge source project
Minecraft Java 1.21.11, Forge 61.2.5, Java 21.

Run BUILD.bat on Windows with internet access. It downloads the official Forge MDK Gradle wrapper and builds the JAR.
Install the resulting JAR in the mods folder on BOTH clients and the Forge server.

This is an untested prototype: the source has NOT been compiled in this environment (Forge Maven is inaccessible). API adjustments may be necessary.
Current stalker uses the vanilla Enderman silhouette and eyes, NOT yet a custom black/white-eyed model.
The 'Unknown joined the game' message is fictional; no real account connects.
